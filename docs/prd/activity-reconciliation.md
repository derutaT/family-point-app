# PRD: 活動突き合わせ機能（活動ビュー & 外部突き合わせ）

> Keyword: `activity-reconciliation`｜関連: 仕様 `docs/spec/` / 決定 `docs/adr/` / 計画 `docs/task_plan/` / タスク `TASKS.md`

## 1. 背景・課題
家族ポイントアプリは「遊び＝ポイント消費／努力＝ポイント獲得」でバランスの取れた日常を作ることを目的とする。現状は次の2点が見えていない。
- **頑張りが振り返れない**: 努力（お手伝い・宿題・継続）にはポイントを付与しているが、その積み重ねを振り返って褒める手段がなく、頑張りを認める機会を逃している。
- **使いすぎが捉えられない**: 申告に依存した運用で、申請せずに行われる遊び（こっそりゲーム等）を捉える手段がない。アプリはアプリ外の遊びを検知できないため、「使ったのに申告しない」状態を是正する仕組みが存在しない。

## 2. 狙い（北極星）
**「見ることで分かる」こと。** 獲得と消費を並べて見せることで、子供が自分の毎日を振り返れるようにする。気づきはポジティブ・ネガティブの両面を含む。
- **頑張りに気づき、認める（ポジティブ）**: 毎日のお手伝い・宿題や、努力を継続できたことが可視化され、褒めるきっかけになる。日々の積み重ねを子供自身も親も実感できる。
- **使いすぎ・未申告に気づき、正す（ネガティブ）**: 実測を並べて見せ、子供が自分で気づいて正直に申告する体験を作る。
- 価値の中心は「自分の毎日を見て、頑張りは誇り、ずれは自分で直す」体験。システムは厳格な制御装置ではなく、称賛も調整も人（子供・親）が行う。

## 3. 対象ユーザー
- **子供**: 自分の遊び/努力を振り返り、未入力分を自分で申告する。
- **親**: 子と一緒に確認し、努力や遊びの量を把握する。もし常態的な不誠実があったときは指摘する。

## 4. スコープ
### やること
- **振り返り（単体表示）**: 努力（獲得）/ 遊び（消費）/ 外部計測 を、それぞれ単独で（他を非表示にして）Day / Week の分量として確認できる。頑張りの承認にも、遊び・実測量の自覚にも使う。
- **比較（並列表示）**: 選んだ2系列を並べて見比べられる。代表例 ①遊び申告 vs 外部計測（実測）→ 子供が自分でずれに気づく ②遊び vs 努力 → 生活バランス（遊んでばかりで勉強できていない 等）に気づく。システムは差を強調・判定せず、並べて見せるところまで（ADR-0001）。
- 外部Activity（計測された記録）の取り込み（手動インポート → 将来 AI 自動化）
- 子供による自己申告（遡及消費）の導線

### やらないこと（明示）
- リアルタイム検知・厳格な利用ゲート
- 精密な誤差計算・閾値チューニング・自動減算
- 不誠実時の自動的な強制対応（＝運用＝人に委ねる）
- 未申告・超過の自動強調・検出（初期は子供が見て自分で気づくに任せる。気づかない／意図的な隠蔽が続く場合に将来検討）
- 既存の単一HTML / localStorage 構成を壊す変更（バックエンド導入等）。※現時点の前提。見直し条件は ADR-0004 参照

## 5. コンセプト: 2つの記録（要約）
- **ポイントの記録**（`pointRecord`／= 申告）= アプリ経由の記録／**計測された記録**（`measuredRecord`／= 実測）= 外部スクショ由来の記録。
- 記録を Day / Week で見える化し、**①単体で分量を振り返る ②2系列を並べて見比べる（遊び申告 vs 実測 / 遊び vs 努力 等）** の両方を表示で支える。申告 vs 実測の突き合わせはそのうちの一つで、検知はシステムに負わせない。
- 定義・突き合わせ単位・データモデルの詳細は spec を参照。

## 6. 方針（価値観）
- **正直さは報酬でなく認知で扱う**: 自己申告に点数報酬を付けない。「自分で申告した事実」を親子に見える形で残す。インセンティブはエスカレーション（2倍ルール）の回避と信用で表現する（ADR-0006）。
- **運用強度**: 既定は2週間に1度、親子で一緒に確認する程度。申請忘れ・たまのこっそり遊びは正常範囲として許容し、常態的な不誠実のみ親が強く介入する。強制はシステム外（ADR-0008）。

## 7. 成功の目安
- 毎日の頑張り・努力の継続が一目で振り返れ、褒めるきっかけになる。
- 努力 / 遊び / 外部計測 を、それぞれ単体で日次・週次の分量として把握できる。
- 遊びと努力のバランスの偏り（遊んでばかり 等）に気づける。
- 子供が申告と実測を並べて見比べ、ずれに自分で気づける。
- 子供が比較ビューから自分で申告（遡及消費）できる。
